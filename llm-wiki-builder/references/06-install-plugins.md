# Stage 6: Configure Obsidian Project

This stage configures Obsidian for the project root. `.obsidian/` lives in `<project>/.obsidian`, and Obsidian opens the whole project as the vault.

Do not install themes and do not write theme settings.

## Existing `.obsidian`

If `<project>/.obsidian` already exists, interactive mode asks:

1. Merge config and install missing plugins (default).
2. Only install missing plugins.
3. Skip Obsidian config.

Non-interactive `--yes` defaults to merge config and install missing plugins.

## Config Merge

Merge or copy these files from `template/base/.obsidian/`:

- `hotkeys.json`
- `app.json`

Preserve existing user keys where possible. Use `jq` for JSON merge when available; otherwise back up and replace only as a fallback.

`app.json` should include:

```json
{
  "attachmentFolderPath": ".llm-wiki/assets",
  "communityPluginsEnabled": true
}
```

## Plugins

Read `llm-wiki-builder/assets/plugin-manifest.json`.

- `core[]` - 9 plugins
- `ux[]` - 7 plugins

For each plugin:

1. Skip when `<project>/.obsidian/plugins/<id>/manifest.json` already exists.
2. Download `main.js` and `manifest.json` from the latest GitHub release.
3. Download `styles.css` if it exists.
4. Add the plugin id to `.obsidian/community-plugins.json`.

When `community-plugins.json` already exists, merge existing ids with newly installed ids and deduplicate.

If Git is unavailable, skip `obsidian-git` and continue.

## Plugin-Specific Config

If `custom-sort` is installed and lacks `data.json`, create:

```json
{"suspended":false,"statusBarEntryEnabled":true,"notificationsEnabled":true,"customSortContextSubmenu":true}
```

## Theme Guardrails

Never create or modify:

- `.obsidian/appearance.json`
- `.obsidian/themes/`
- `cssTheme`
- `accentColor`
- Minimal theme
- Minimal Settings plugin

If `.obsidian/appearance.json` was generated by an older run, remove it during configuration so the installer does not keep enforcing theme state.

## Verify

After this stage:

- `.obsidian/plugins/` contains installed plugin directories.
- `.obsidian/community-plugins.json` keeps old ids and includes installed ids.
- `.obsidian/app.json` has `communityPluginsEnabled: true`.
- `.obsidian/appearance.json` does not exist.
